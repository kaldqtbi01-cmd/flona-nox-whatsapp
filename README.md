### ✨ إضافات جديدة

تظهر الأوامر التالية تلقائيًا كأزرار في أقسامها داخل قائمة `.menu`:

- `غائب` و`رجعت` — حالة غياب مع تنبيه عند ذكر العضو.
- `مضاد_تعديل تشغيل/إيقاف` — تنبيه المجموعة عند تعديل رسالة.
- `جدولة` — جدولة نص لإرساله لاحقًا، مع قائمة وإلغاء.
- `تتريس` — لعبة تتريس نصية تفاعلية.
- `حساب_جينشن` — عرض ملف Genshin العام برقم UID.
- `تعرف_الانمي` — البحث عن الأنمي من صورة لقطة.
- `استخراج_نص` — استخراج نص عربي من صورة، ويتطلب `OCR_SPACE_API_KEY` في `.env`.
- `عرض_شرائح` — طلب نسخة PDF/PPTX من رابط SlideShare عبر خدمة خارجية.

تتطلب بعض الإضافات اتصالًا بالإنترنت، وقد تتأثر بتوقف الخدمات الخارجية أو تغيّرها.

### 🔐 إعداد مفاتيح الخدمات

انسخ نموذج الإعدادات إلى ملف محلي غير متعقّب، ثم أدخل مفاتيح الخدمات التي تحتاجها فقط:

```bash
cp secrets.env.example .env
chmod 600 .env
npm ci
npm start
```

لا ترفع `.env` أو مجلد `auth_info_baileys/` أو `sessions/` إلى Git. إذا كانت مفاتيح خدمة قد ظهرت في نسخة عامة سابقة من المشروع، فألغِها أو دوّرها من لوحة مزود الخدمة قبل إدخال مفاتيح جديدة. راجع [سياسة الأسرار والمصادر](docs/SECURITY-AND-SOURCES.md) للتفاصيل.
