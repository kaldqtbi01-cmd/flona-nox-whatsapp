# تقرير ترتيب قائمة أوامر FLONA

## النتيجة المختصرة

وُحّدت أسماء الأقسام القديمة في **10 أقسام رئيسية**، وأُضيفت بيانات عرض للأوامر التي كانت تعمل من دون `handler.help`. بعد إزالة التكرار داخل كل قسم، تعرض القائمة **473 تسمية أمر**؛ منها **61 تسمية جديدة صافية** في هذا التحديث. كانت هناك 62 تسمية مساعدة مرشحة للإضافة، لكن تسمية «حالة» كانت موجودة مسبقاً في القسم الرئيسي، فظهرت مرة واحدة فقط.

الأعداد التالية تحصي تسميات الاستخدام المعروضة في القائمة؛ لذلك تُحسب المرادفات وصيغ `on/off` كلٌ على حدة. عمود «أُضيفت الآن» هو صافي ما ظهر للمستخدم للمرة الأولى بعد إزالة التكرار.

| القسم الموحد | إجمالي التسميات بعد الترتيب | أُضيفت الآن |
|---|---:|---:|
| الرئيسية والمعلومات | 36 | 13 |
| إدارة البوت والمطور | 61 | 10 |
| الذكاء الاصطناعي | 21 | 0 |
| الأنمي والمانجا | 48 | 3 |
| الاقتصاد واليوميات | 32 | 0 |
| الألعاب والترفيه | 101 | 8 |
| المجموعات والحماية | 78 | 20 |
| التنزيل والإنترنت | 44 | 4 |

| الأدوات والخدمات | 36 | 3 |
| **الإجمالي** | **473** | **61** |

للمقارنة، كان مجموع القائمة بعد توحيد الأقسام وإزالة التكرار، وقبل إظهار بيانات المساعدة الناقصة، **412 تسمية**. يشمل هذا العدّ 21 تسمية مساعدة في `subs-ajustes.js` التي تُولّد وقت التشغيل من قائمة أوامر الإضافة نفسها.

## توحيد الأقسام والوسوم

| الوسوم القديمة أو المتقاربة | القسم الموحد |
|---|---|
| `main` و`info` | الرئيسية والمعلومات |
| `owner` و`serbot` | إدارة البوت والمطور |
| `ai` | الذكاء الاصطناعي |
| `anime` | الأنمي والمانجا |
| `economy` و`daily` | الاقتصاد واليوميات |
| `game` و`games` و`fun` و`ترفيه` | الألعاب والترفيه |
| `group` و`grupo` و`مجموعة` و`protection` و`nable` | المجموعات والحماية |
| `download` و`downloader` و`internet` و`search` | التنزيل والإنترنت |
| `sticker` و`image` و`editor` | الصور والملصقات |
| `tools` و`herramientas` و`utils` و`misc` و`قسم الأدوات🛠️` | الأدوات والخدمات |

تظل أسماء الوسوم القديمة مقبولة كاختصارات للقسم الموحد، لكن القائمة تعرض اسماً واحداً فقط لكل قسم. كما يُعرض أمر الإضافة متعددة الوسوم في قسم واحد مناسب، وتُزال التسميات المتكررة داخل القسم.

## الأوامر التي أُظهرت للمرة الأولى

- **الرئيسية والمعلومات: 13**؛ كانت 14 تسمية في الملف الناقص، لكن «حالة» موجودة مسبقاً.
- **إدارة البوت والمطور: 10**.
- **الألعاب والترفيه: 8**.
- **الأنمي والمانجا: 3**.
- **المجموعات والحماية: 20**.
- **التنزيل والإنترنت: 4**.
- **الأدوات والخدمات: 3**.

الإضافة `Human ai.js` لم تُدرج لأنها ليست أمراً مباشراً (`handler.command = false`). ونُقلت اختصارات الأقسام السبعة إلى القسم الذي تفتحه، مثل اختصار الألعاب إلى الألعاب واختصار الحماية إلى المجموعات والحماية؛ بينما بقي اختصار الألقاب ضمن الرئيسية والمعلومات.

قد تتكرر بعض التسميات نفسها بين إضافتين مختلفتين إذا كانت كل إضافة تقدم وظيفة مستقلة، مثل «متجر» للاقتصاد ومتجر لعبة المدينة. أما تكرار الوسوم أو التسميات داخل القسم نفسه فيُدمج.
