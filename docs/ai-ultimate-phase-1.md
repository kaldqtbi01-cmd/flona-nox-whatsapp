# FLONA AI Ultimate — المرحلة الأولى

هذه المرحلة تضيف نواة تشغيل موحدة فوق اتصال FLONA الحالي، ولا تنشئ اتصال WhatsApp أو جلسة جديدة.

## الوحدات المنفذة

- `lib/ai-core.js`: غلاف موحد يجمع المزودين والتخزين المؤقت والقوالب والاستهلاك والصحة والصلاحيات والجدولة.
- `createAICache`: ذاكرة مؤقتة محدودة بـ TTL وحد أقصى للعناصر.
- `createPromptManager`: قوالب آمنة باستبدال متغيرات فقط، دون تنفيذ كود.
- `createUsageMonitor`: عدادات الطلبات والأخطاء والرموز والتكلفة التقديرية الاختيارية.
- `createPermissions`: قرارات أولية للمالك والمشرف وإجراءات المجموعة.
- `createHealthMonitor`: حالة آخر نجاح أو فشل لكل مزود.
- `createTaskScheduler`: جدولة داخل العملية بحدود زمنية وعدد مهام.
- `createAICore`: يستدعي `global.aiProviders`، يضيف cache وusage وhealth ويعيد نتيجة منقحة.

## الربط

تم إنشاء `global.aiCore` في `src/index.js` بعد تحميل `.env`، مع إبقاء `global.aiProviders` متاحًا للتوافق. لم يتم تعديل Baileys أو الجلسة أو PM2.

## الفحص

الأمر الجديد الحالي:

```text
.حالة_الذكاء
```

يعرض حالة Groq وGemini وعدد عناصر cache والمهام المجدولة، ولا يعرض أي مفتاح.

## الاختبارات

اختبارات المرحلة:

```bash
node --test tests/ai-core.test.js tests/ai-provider.test.js tests/rare-features-foundation.test.js
```

لا تتصل هذه الاختبارات بمزود خارجي ولا ترسل رسائل WhatsApp.

## القيود

هذه المرحلة لا تدّعي إكمال الوكيل المستقل أو قاعدة المعرفة أو التوأم الرقمي أو مركز القيادة. هذه الوحدات تحتاج طبقات domain وأوامر Plugins مستقلة ستنفذ في مراحل لاحقة بعد اختبار كل مرحلة.
