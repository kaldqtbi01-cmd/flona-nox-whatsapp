# Security, Automation & Health Phase

## Commands

```text
.صحة_النظام
.أمن
.أتمتة
.أتمتة اقتراح
```

- `.صحة_النظام` يعرض حالة المزودين وCache والمهام والمحركات بدون أسرار.
- `.أمن` للمالك ويعرض ملخص أحداث الحماية المسجلة.
- `.أتمتة` يعرض أتمتة المستخدم في المحادثة.
- `.أتمتة اقتراح` ينشئ اقتراحًا محفوظًا بحالة `draft` ولا يشغله.

## Safety

Security Center يرصد مؤشرات الأسرار وحقن التعليمات ومحاولات تنفيذ الكود، وينقح الأسرار عند التسجيل. لا توجد عقوبة تلقائية.

Automation Control لا يشغل أوامر نظامًا ولا يرسل رسائل، وكل اقتراح يبقى للمراجعة.
