# FLONA AI Ultimate — المرحلة الثانية

## الوحدات المنفذة

- `lib/agent-memory.js`: ذاكرة طويلة المدى مع عزل حسب `scope` و`owner`.
- `reconstructContext`: يجمع نافذة الرسائل والذكريات الخاصة بالمحادثة.
- `createAgentEngine`: تخطيط وتنفيذ محدود بخطوات مسموحة فقط.
- الخطوات المسموحة: `answer`, `summarize`, `remember`, `draft`.
- لا يوجد تنفيذ أوامر نظام أو HTTP أو حذف أو إرسال تلقائي.
- خطوة `draft` تنشئ مسودة `pending` داخل Human-in-the-loop وتحتاج موافقة المالك.

## الأوامر الجديدة

```text
.ذاكرة حفظ <معلومة>
.ذاكرة عرض
.ذاكرة بحث <كلمة>
.ذاكرة حذف <المعرف>
.إعادة_السياق
.وكيل <المهمة>
```

الذاكرة الخاصة بالمستخدم لا تظهر لمستخدم آخر في نفس المجموعة. أمر الوكيل يستخدم AI Core للتخطيط عند تشغيله، ثم يطبق الحدود السابقة.

## القيود الحالية

الوكيل ليس منفذًا عامًا للأوامر، ولا يملك أدوات نظام أو تصفح. التوأم الرقمي، مجلس الوكلاء، قاعدة المعرفة الحية، التنبؤ، ومركز القيادة ستأتي كوحدات مستقلة لاحقًا.
