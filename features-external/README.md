# External feature files

هذه الملفات نُسخت كما هي من المشاريع المصدرية بعد فحصها، لكنها ليست جزءًا من runtime FLONA ولا تُستورد من `src/index.js` أو `handler.js`. الملفات الخاصة بـ Baileys وauth/session وQR وCloud API وPrisma/Postgres وRedis وcode-exec لم تُنسخ. استخدامها لاحقًا يتطلب تكييفًا واختبارات وتحققًا من التبعيات والتراخيص.
